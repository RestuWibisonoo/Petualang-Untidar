# Petualang-Untidar

Game 2D Top-down Action Adventure RPG bertema petualangan Universitas Tidar (Untidar).

## Spesifikasi Teknis
- **Game Engine:** Godot Engine 4.7.2
- **Bahasa Pemrograman:** GDScript (Strict Typing 2.0)
- **Renderer:** GL Compatibility (OpenGL ES 3.0 / WebGL 2.0)
- **Target Platform:** Web (HTML5/Wasm) & Android (APK/AAB)
- **Gaya Visual:** 2D Pixel Art
- **Sistem Gerakan:** 8-Directional Movement
- **Karakter:** Modular Customization Rig (Body, Hair, Clothes, Armor, Accessories, Weapon)
